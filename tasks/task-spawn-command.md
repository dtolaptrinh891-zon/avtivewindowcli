# 📋 task-`spawncommand`.md — Task Definitions for onodecli `spawncommand`

## **prompt user:**

**Bổ sung command:** `onodecli spawncommand`

**Mục tiêu command: Sẽ truyền các các args là command của các lệnh khác, hãy xử lý để spawn qua để chạy các command này. Để giải quyết vấn đề, có nhiều command cli khác, giờ chỉ muốn tập trung vào một nơi để chạy và gọi được.**

**Các ví dụ lệnh cần chạy:**

- ocli cloudflared
- ocli gh
- ....

Lưu ý: các lệnh này có thể có user active, để chọn, gõ các tham số..
